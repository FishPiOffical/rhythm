## 行为

匿名文章仅有效本人概要，评论只含当前可读文章中的本人匿名评论；是否列出由后端当前权限判断。总数/pageCount取服务端，不用公开主页文章/评论数补数。标题普通文本；仅链接到文章，评论额外明确ID，不声称进入文章就能自动定位任意页评论。元数据无正文，私密评论只标状态，不抓旧接口绕过当前权限。

列表失败独立错误，不显示“暂无”或保留旧页冒充新页；第二页可原页重读或返回第一页。普通token轮换保留页；退出、换号、目标用户名/文章评论类型变化清旧列表/错误并回第一页，迟到结果不能覆盖新身份。没有SWR/持久化私有缓存。SSR仅准备态，不查本人列表，不输出本人标题/评论ID；挂载后取当前账号。页面noindex，不在SSR预取旧公开资料。

## 完整人工链

1. 真实联调先由IDEA重新编译/重启此前Java/FTL并部署所需迁移；本批仅客户端，运行前端构建。第一方登录→设置→数据→本人匿名文章/评论，或本人主页匿贴/匿回，原路径可直接打开，不依赖旧公开userinfo成功。
2. 准备本人有效/无效匿名文章及普通/私密匿名评论；核标题/ID/创建更新时间、真实总数/分页。普通公开创作不能混入；已删除或当前讨论权限不满足的评论目标不能列出。点击文章链接走既有详情当前授权，不出现匿名真实作者ID/正文/高敏资料。
3. 超20条分别翻页，第二页503后重试或回首页，末页禁下一页；空结果与失败明确区分。模拟坏分页/重复ID/非法时间响应应报格式错误，不显示半份数据。标题中的标签不执行。
4. 普通401刷新保留当前页；退出/换号/改名、切文章评论或快速换路由时清旧列表，旧慢响应不回写。直接打开他人匿名路径显示本人限制，不自动将本人的匿名记录挂在他人路径下；未登录引导登录。
5. SSR HTML不含本人记录或私密ID，挂载无水合警告；PC/移动/键盘/读屏、真实Cookie/Bearer、撤权/停用及跨设备另验。真实阅读权限/讨论邀请/私密双方矩阵仍须后端测试库核实，夹具不能替代。
