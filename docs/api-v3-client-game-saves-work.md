## 人工完整测试链

1. 登录进入设置→数据`/settings/data`，读取Evolve目录和当前本人存档。无新存档404应显示首次保存/显式迁移；目录或存档读取503/格式错误应显示错误，不伪造空槽或允许凭未知版本覆盖。
2. 输入含首尾空白、换行、emoji、HTML字面量的游戏导出字符串，保存时核对原版本并确认。首次用0，成功新版本1；覆盖用当前读取版本并递增。保存成功自动查询当前版本/字节/hash，编辑框不清空。读取不会自动替换已有草稿；点击载入云内容时，非空编辑框需确认。
3. 用两客户端先读同版，再让另一端保存。当前端保存应409且不自动重发/覆盖；草稿保留，重新读取新版本后由用户再次确认保存。空字符串是合法覆盖，确认文案须明确；超长/无效Unicode被拒绝，不trim或截断。
4. 用开发代理模拟保存已提交但响应503：离开数据页，从全局恢复原操作。应相同原文/expectedRevision/幂等键，数据库只写一次。成功回执与当前GET分开；GET失败只重读，不再增加版本。若其他端已存更高版本，原回执仍为当次版本，当前读取显示最新版本，不覆盖草稿。
5. 无新槽时显式迁移本人唯一旧记录，成功后读新槽且不自动插入编辑框。旧记录缺失404、旧记录重复/已有新槽409、坏旧内容422均不得部分写入或自动挑选；同键回放不覆盖后来存档。
6. 未确认时新保存/迁移按钮阻止替换原命令；平台要求二次确认时先明确确认。正常令牌轮换保草稿及待恢复命令，退出/换号清当前正文/草稿/回执。慢请求后退出、打开确认后离页，迟到数据不得恢复或继续写入。SSR不读取/输出本人存档，整页刷新不会保留内存恢复命令。
