website_v3 实际文件：

- `src/stores/v3FishGames.ts`：唯一原命令/原幂等键，未知结果恢复、平台明确确认及身份隔离。
- `src/composables/useFishGames.ts`：列表、当前详情和评论独立读取/错误/页码，排序重置第一页，原页重试与迟到隔离。
- `src/components/FishGameEditor.vue`：投稿和本人编辑共用五字段表单，OAuth网址必填，不造默认值；待审不等于公开批准。
- `src/components/FishGameRecovery.vue`、`src/layouts/AppShell.vue`：唯一全局原操作恢复提示，不显示私有表单原文。
- `src/views/GamesView.vue`：保留官方/活动游戏入口，新增真实社区鱼游目录和详情、评论分页、明确投票、本人编辑入口，移除“暂无公开JSON”提示。

- `tools/v3-fish-games-test.mjs`：真实 TS/Pinia/composable/Vue 页面/表单/SSR 隔离测试。
- 两仓进度文档、AGENTS.md、本记录；后端 UPDATE_LOG.md 更新公开行为。

默认沿已确认规则总投票优先，也可选点赞优先，每页20条。选择鱼游才读详情与评论。写成功后独立 GET 当前数据，历史回执计数/评论正文不直接写入界面，编辑申请不覆盖公开内容。新投稿可能尚未公开，不以详情404推翻申请成功。

官方游戏是经典站点链接，依赖经典站点登录态；不把内存 Bearer 当 apiKey 换 Cookie。新表单采用服务端已确认的五个必填字段，图标不再标可选。OAuth由服务端检查授权URL参数及同站回调，客户端不声称验证归属或实际完成授权。原始字符串送服务端清洗；表单原文有界、无效Unicode/控制字符拒绝，名称/描述清洗后80/1000、评论500限制最终由服务端裁决。

未知写结果跨 SPA 离页保留原目标/原正文/原投票/原键；正常轮换保留，退出/换人清除。刷新浏览器不能恢复内存命令。GET失败只重读，不能重发写；平台要求确认时必须明确同意。本人编辑原公开字段可预填，OAuth必须重新输入；同账号普通轮换保留未提交编辑快照。公开响应不含当前待审正文或OAuth，界面不能从GET推算审核进度。

## 安全与反漏扫

读取沿已有 optionalContent 与 AnonymousViewCheckMidware，写沿已有精确 scope 与写守卫；总注册接线已核对。未改 anonymous.viewSkips、BeforeRequestHandler、验证码解封或公开路由。真实未鉴权/越权/缺scope/CSRF/撤销令牌、黑名单→/test→validateCaptcha、首访与周期验证及开发关闭风控仍未运行验证。

固定资源路径+有界ID/分页/字符串、只发白名单字段，客户端不含SQL和服务端远程抓取，不新增注入或SSRF入口。游戏/图标仅安全HTTP(S)/同源路径投影，写入URL要求HTTPS；点击新窗口有noopener/noreferrer，图标不发Referer，正文/作者/错误均文本插值。隐藏评论强制丢弃返回的正文。没有新增凭据存储或公开上传/下载地址；批量滥用与最终权限由真实服务验证。

没有新增CDN依赖、source map或可枚举静态目录。审计只覆盖本轮产物，不代表生产CDN/历史路径与全站目录枚举已经验收。

## 完整人工验收

1. 构建前端，强刷 /games。访客可见社区鱼游，默认总票优先；切点赞排序回第一页，前后页总数准确；503应清旧列表并显示原页重试，空结果明确显示。打开详情/评论、关闭/快切目标，迟到结果不能回填。
2. 登录在详情依次点赞、再次点赞、点踩、清除。检查PUT/PUT/PUT/DELETE，成功后GET当前计数和userVote；再次设置同值不取消。模拟写成功后GET503，只重读不再投票。
3. 投稿填齐名称、简介、HTTPS游戏/图标以及符合说明的OAuth授权网址；成功显示申请编号和待审说明，不伪造公开作品。本人已审核作品可申请编辑，预填公开字段，OAuth重新填；修改在审批前不影响公开内容。非本人无编辑入口，直接越权应404；已有待审/未审核编辑应409。
4. 评论含HTML/首尾空白由服务端清洗，成功后重读第一页并清匹配原稿；空白/清洗后超500、非法字符422，不伪造成功。失效作者正文显示不可展示，禁止输出原隐藏内容；评论分页失败按原页重试。
5. 五字段分别测空值、名称清洗后超80、描述超1000、非HTTPS/超512 URL、OAuth超4096/重复或未知参数/伪装站点回调；应失败且无申请。真实合规OAuth实例需服务端验收。
6. 测试环境模拟提交已完成但响应中断，离页后从全局恢复原投稿/编辑/评论/投票和原键，仅生效一次；未知403仍保原命令，新操作不能覆盖。平台确认明确同意才发；退出或换号清理，正常轮换保留原命令和未提交编辑稿。
7. 桌面与390px检验表单/分页/图片/链接、SSR挂载无警告。官方游戏应正常进入经典站点，未登录由该站点处理。真实服务补验401/403、匿名和黑名单验证码链、撤销令牌、并发写幂等、审核前后及权限；不使用生产账号制造测试投稿或评论。
