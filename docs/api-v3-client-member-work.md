# v3 用户主页（2026-10-27）

本批迁移MemberView及主页SSR，复用现有公开资料、用户文章/评论/清风列表和单条清风GET，后端注册285条不变。没有Java/FTL/SQL/APP改动，未执行Maven；API.md现有契约不变。

## 实际修改文件与行为

website_v3：
- `src/api/v3-member-content.ts`：四种列表（普通文章/长文章/评论/清风）真实分页，固定20项、latest/type分流；严格页码、响应分页、作者归属/署名及重复ID校验。评论绑定文章ID并复用正文可见性适配；清风深链接直接查ID并复核用户名归属，不再从最近30项猜测删除。
- `src/composables/useMemberPage.ts`：资料/当前列表独立请求、错误与重试。目标/栏目/身份代际绑定，正常token轮换保留页，换号重置；退出和卸载拒迟到内容，无旧SWR快照回退。SSR只消费本次公开资料，不发客户端列表请求。
- `src/views/MemberView.vue`：公开六字段、现有v3昵称样式、ID绑定关注/本人操作、私信/转账/举报入口保持。列表真实总数/分页/失败重试、文章共用ArticleFeed、清风共用BreezemoonList、评论保留文章锚点及私密不可见提示；职业和勋章/关系导航保留。去掉未提供的角色/在线/积分/编号/城市/MBTI/旧勋章默认或合并，禁止把缺失字段当0/离线/黑客。积分仅引导本人已有积分页。SCSS桌面两列、窄屏单列；外层无卡片包裹子卡片。
- `src/entry-server.ts`：公开主页SSR用fetchPublicUser六字段投影，不查询旧完整用户资料。
- `src/seo/payload.ts`：member改PublicUser，消费时再次decodePublicUser，未知字段不进入组件。
- `src/api/fishpi.ts`：删除已无调用者的fetchUserProfile/fetchUserArticles/fetchUserBreezemoons/fetchUserMedals四个旧包装；其他旧包装仍待实际消费者审计。
- `tools/v3-member-page-test.mjs`：13组API、实际组合函数和完整Vue页测试；`tools/v3-ssr-payload-test.mjs`使用真实公开解码依赖并强化敏感字段丢弃/单次消费；`tools/v3-public-professions-test.mjs`同步新职业组件分支位置。
- 两仓AGENTS、本记录与迁移总表；Rhythm另更新UPDATE_LOG。

公开画像只提供六字段，未提供的背景、身份、活动统计等展示能力仍属契约缺口；没有因此添加未经确认的公开敏感字段。勋章图片仍是上一批已记录的缺口。不能据此声明全站旧接口已清完或v3整体完成。

## 完整人工测试链

1. 从首页署名/用户卡片进入`/member/{userName}`，游客与已登录分别验证头像/昵称/简介/个人网址；HTML应按字面展示，网址安全新窗口。页面和SSR源不应含手机/邮箱/QQ/凭据，也不应补假积分、在线状态或角色。
2. 本人应见编辑资料/匿贴匿回/我的积分，他人应见关注/私信/转账/举报；关注应绑定公开ID，私信目标编码正确。按实际已有写接口授权分别操作；本批未在真实账号执行这些写入。
3. 准备超过20条署名文章，普通/长文章分别进入，验证latest、type、总数、末页按钮及短页滚回内容。第二页模拟503：旧行和总数清空、资料保留，重试仍p2；合法0与403/404不同，禁止失败退旧接口。
4. 回帖页核对普通/段评记录和文章锚点；无权私密正文为空且显示不可见，授权读者由服务端决定。匿名、讨论帖及不可列出目标不得通过公开列表关联，真实后端过滤需实测。
5. 清风明月翻页并点击“查看这条清风”，应按精确ID取得当前作者详情，超出原30条仍可读；其他用户ID、删除或不可读时明确错误，可重试，不能误说只是最近列表缺失。
6. 切换职业、公开勋章、关注/粉丝、标签/收藏/订阅页，各自走既有v3资源；不再主页后台预取旧会员/勋章。职业模块不能因主职业或旧资料字段缺失而隐藏。
7. 快速切目标/栏目，延迟旧响应；旧内容不得覆盖当前。正常token轮换保持页码，退出/换号重置，离页迟到不得复活；转账面板换身份/目标关闭。桌面/390px、长网址、键盘导航和触控布局需要实际检查。
8. 真实服务检验游客匿名校验、Bearer缺scope/失效/停用、列表隐私403、黑名单/test、首访/周期验证码及validateCaptcha解封、开发风控关闭、频繁请求和目录枚举响应。以上仍待运行验收。

## 安全与反漏扫复核

现有资料GET保留optionalProfile，用户列表/单条清风沿optionalContent及AnonymousViewCheckMidware，不改Before黑名单、验证码解封或anonymous.viewSkips。仅新增客户端GET调用，无新Cookie写或CSRF入口；既有关注/私信/转账/举报写边界保持。用户名闭集/编码、分页边界、字段白名单、作者归属和身份代际均有测试，避免混目标/敏感对象传播。昵称/简介/标题纯文本；评论/清风仅使用现有服务端清洗contentHtml，私密正文适配层置空，不使用原始content作为HTML。

无新增SQL或远程抓取，无新增上传/下载路径/目录/CDN，静态版本/map审计通过；当前栏目单页读取，不预取全部目录或旧完整用户，失败只显式重试。真实越权/未鉴权/匿名盾/限流/目录响应和设备布局未运行验收，不默认通过。接口契约没变，经典PC/mobile皮肤与APP不涉及。
