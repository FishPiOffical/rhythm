修改`src/components/user/UserHoverCard.vue`：改v3读取、明确同目标重试；删除无限期LRU，每次重新打开读取当前资料。正常token轮换重读打开中的目标，退出/换身份/路由变化隐藏并拒迟到响应。去除契约未提供的背景、MBTI、勋章、角色、编号、积分、城市和在线/离线显示，不补假角色或状态；会员昵称样式以公开ID查询既有样式资源。关注及私信入口保留，自己按ID判断。网址可访问名称、URL编码、安全外链与SCSS源同步。

修改`src/components/user/UserFollowButton.vue`：新增可选内部组件userId属性，已知公开ID直接绑定关系GET/PUT/DELETE，避免按用户名再次解析改变操作目标；只传userName的既有调用保持。ID进入异步身份边界，自己ID无关系请求。

新增`tools/v3-user-card-test.mjs`十二组；修改`tools/v3-user-follow-test.mjs`增加第八组已知ID读取/写入/本人保护。两仓AGENTS/本记录/迁移总表及Rhythm UPDATE_LOG同步；API.md现有契约不变。

## 完整人工测试链

1. 从首页/排行榜/文章的署名头像或用户名进入，鼠标移入打开卡片，或键盘Tab聚焦用户名。核对v3目标用户名、公开ID和六字段；昵称/简介中的HTML必须显示字面文本，不能执行；缺字段不伪装为黑客/离线/0积分。SSR不提前查询任意目标。
2. 模拟目标503/404，卡片显示读取失败且无旧资料，点“重试用户资料”仅重读同一v3目标。关闭后重新打开应查当前资料，停用目标不能继续显示此前成功内容。非法网址不显示链接，合法HTTP/HTTPS保留完整query，安全新窗口打开。
3. 登录他人卡片应显示关注和私信；本人按ID隐藏两操作，不因用户名快照变化而错误认定。关注读取/明确PUT或DELETE沿既有原命令恢复，已知卡片ID直接绑定；私信进入既有v3会话链。本批只改关注组件的可选ID绑定，不改变服务器授权。
4. 快速在两用户间切换并延迟第一请求，旧资料不得覆盖第二人。正常token轮换重读当前目标；退出/换号/路由跳转、Escape或离开交互区应清卡片，晚到响应不得复活。重试按钮和卡片内部链接获得焦点不应误关闭。
5. 桌面和390px手工检查左右侧定位、滚动/缩放/长文本、打开/关闭动画和重试可点击；触屏点头像应正常进入主页，不弹悬浮卡遮挡。真实窄屏与物理鼠标/触控未在本批完成浏览器验收，需实际补验。
6. 游客走既有匿名访问验证；登录Bearer缺profile.read、账号停用、黑名单/test、首访及周期验证码、/validateCaptcha解封、开发风控关闭和接口频繁调用失败均应按既有规则处理，不使用旧接口绕过。
