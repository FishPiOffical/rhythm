发布/修改/删除成功只确认回执与编号，然后丢弃旧缓存并强制重读当前文章页、段评和统计；失败显示单独“重读评论”，不重复写入。余额刷新失败独立提示。原草稿仅在匹配提交完成且未再修改时清除；编辑器普通草稿未新增持久化，整页刷新/退出清本地恢复信息。成功发布不自动跳到最后一页；新回复可能在其他页，应通过分页查看。当前段评内取消回复或发布完成保留当前段落，旧操作恢复不覆盖后来选择。

长篇详情额外取paragraphs includeContent=true的当前带锚点HTML；统计分页完整读取、重复/漏项或数量变化明确失败，不拿0冒充未知。段评按现有v3平铺分页，回复标原评论ID，不伪造按根分页的旧层次；所属文章/锚点/state逐条验证，私密正文/匿名作者白名单投影。读错明确重试，统计/列表迟到请求有序号及身份约束。段评侧栏本人可编辑/删除并恢复未确认命令。CommentItem不再给无公开ID作者生成假主页链接，不可见正文显示明确提示，并设置真实评论锚点。

## 人工完整用户链路

1. 联调前须先由用户用IDEA重新编译/重启前批Java；本批仅客户端无需因本批重启Java。登录用户站进入他人普通文章，发布含Markdown及首尾空白的评论，费用确认取消时无请求；确认后见评论编号、当前列表和真实流水。回复一条评论，检查parentId和层次；空白、4097字符、未绑定手机、禁止评论、无权限/余额不足均不得发布或扣款。
2. 新建匿名与仅楼主可见评论，分别用本人、楼主及无关读者读取：后者只有不可见提示，匿名不出现真实ID或假主页。当前匿名本人编辑/删除按钮仍缺本人管理证明入口，不作为本批完成项。
3. 本人公开身份评论点击编辑，必须取原始Markdown而非HTML；默认保存保留原可见范围，显式改为公开/仅楼主才提交visible。窗口内/外费用按平台核对。原文503不能填假内容，重读后再编辑；非本人、锁定目标或正文审核拒绝不修改。
4. 本人符合删除条件的评论确认删除（平台当前费用、默认100），列表重读后移除；有回复/投票/感谢/采纳、余额不足或无权限时拒绝且不扣费。删除丢ACK后从恢复按钮原DELETE/key重试，不换新键删除。核对账款、通知及reaction清理的真实后端效果。
5. 打开长篇段评按钮，应使用当前paragraphs锚点；发布独立段评、回复，再取消回复连续发段评仍保留该段落。切换正文版本/失效锚点、目录409/503、平铺分页/热门、统计失败与重试不能展示假0。本人公开身份段评编辑/删除及未知恢复也应刷新当前段评列表；跨段回复不得串目标。
6. 模拟POST/PUT已提交丢响应，跨SPA到另一文章恢复：路径/输入/键保持原操作，当前文章不接收原正文。模拟写成功后GET503，只点“重读评论”，不得追加写入。正常token轮换保留未知命令，退出/换号清除；原文/确认等待中离页、切目标或退出后不得回填/发送旧操作。
7. 桌面及390px移动视口回归普通/长篇编辑器、确认/错误/段评侧栏，键盘可操作、无横溢出和新增hydration警告。富文本上传、真实极验/风控、真实文章Socket及其余互动仍单独验收。
