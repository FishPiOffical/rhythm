## 人工完整链

1. 本轮只改客户端；真实联调仍先确认前批Java/FTL已IDEA重新编译/重启，已有会员/积分索引迁移部署。客户端yarn run build，指向localhost:8080，通过127.0.0.1:5173打开/vips。使用专用开发测试账号与可回收积分/券，勿直接拿生产账户自动开通。
2. 匿名仅登录入口；本人登录读真实档位/周期/天数/价格与当前状态，永久会员到期显示永久、开通按钮禁用。状态/目录失败不显示未开通假默认、不允许写；目录跨页完整、不漏未知周期类型，定义冲突明确报错。
3. 使用无效/非折扣/用尽券确认后应422且积分/会员/券/礼包均不变；余额不足409。有效券按服务端结果扣款，核对实际paidPoints、到期自然日、默认配置及确认档位对应礼包/背包上限；价格不由客户端计算或指定。确认取消不发POST；确认期间切换账号不得提交旧购买。
4. 注入开通已提交但响应丢失，保留原命令/key，其他写禁用，重试不再次扣分/用券/赠包。成功后GET/账户刷新失败仍显示已确认开通，只重新读；已经有效或永久的账号不能重复开通。若已离页/刷新先核对当前会员/积分/背包，不依赖已丢失的本地命令恢复。
5. active且找到当前定义：只显示支持的bold/underline/color；旧空配置显示未设置，改颜色不能顺带写false。配置仅发改动项，其他权益只读且保持；当前实际配置与档位默认值区分。VIP1/2/3及类似VIP4_FOO不能用效果，精确VIP4_YEAR/MONTH才可用，普通颜色严格6位。未知保存结果同键恢复，后来修改后旧key不覆盖当前读取。
6. 切换账号/退出/卸载时挂起读写与确认弹窗，不串本人状态、优惠券、草稿/回执；PC/移动完整走读→确认→保存→刷新→异常恢复。无Bearer、仅Cookie/apiKey、缺content.read/profile.read/settings.write/activity.write、失效token/epoch或停用账号按对应接口拒绝，不能指定他人账户。
7. 核对开通后真实昵称预览、账户余额、会员状态及共享昵称缓存刷新。共享昵称旧读取/他人主页会员判断仍有后续迁移范围，不能据本页通过宣称整站会员全v3；全站样式是否生效须真实服务联调。
8. 回归Before黑名单/test、匿名验证/解封、CSRF/Bearer、批量请求，以及全CDN版本/sourceMappingURL、目录枚举、上传下载返回路径。本轮没有新增这些后端入口，但真实全链未验，不默认通过。

## 安全与反漏扫

沿既有v3 Bearer/scope写入与读取门禁，不新增匿名路由、viewSkips、Cookie/apiKey例外、SQL或上传下载。请求无userId/价格/configJson/任意权益；客户端资格仅表单辅助，最终价格、余额、券、资格和事务由服务端重验。券不写localStorage/URL或本组件日志；命令只内存并绑定凭据边界。

响应白名单、字符串/ID/枚举/条数/整数有界，Vue文本、颜色白名单与既有纯函数预览，无v-html/动态SQL/远程抓取。当前目录价格可能在确认后变化，页面明确按提交时服务端价格/券结果结算，既有API未增加价格锁定契约。

生成JS定向扫描零命中，无新公网CDN。真实支付前后账款/礼包原子性、权限撤销时序、完整应用/设备、黑名单验证码、负载与全CDN/目录/上传下载未验；隔离前端与夹具不能替代。旧共享昵称读取仍存在，未据此声称无旧API或整站会员隐私审计完成。
