## 修改文件及行为

website_v3：

- `src/api/v3-directory.ts`：固定domains/tags两种目录，每页50；请求、响应页号/页大小/总数/页数及重复ID校验。固定白名单投影，图标拒绝可执行协议/凭据/控制字符，保留合法HTTP(S)或本地路径。SSR数据再次投影并绑定目录和第一页，不能把别的目录快照套入当前页。
- `src/composables/useDirectory.ts`：独立加载、刷新、原页重试；失败清旧数据与旧总数，序列/认证上下文/Token/actor/卸载校验迟到结果。同账号普通轮换保页，退出换号回第一页；公开SSR成功首屏不重复读取，登录后重新按当前身份读取。
- `src/views/DomainView.vue`、`src/views/TagsView.vue`：移除旧SWR与apiKey路径，真实总数/页数，末页禁下一页、目录收缩时可返回第一页；未读/失败/成功空态分开。领域从整库聚合改为50项分页，标签不再按50条猜下一页；链接只用已验证ID，不二次解码标签名称。标题/说明仅Vue文本，标签0篇计数保留。外层透明布局、子项同级，源码SCSS含响应式规则；翻页scroll-margin避开固定顶栏。
- `src/entry-server.ts`、`src/seo/payload.ts`：目录公开首屏统一directoryPage，按应用一次消费和当前kind白名单；旧无调用payload兼容helper仍保留，不宣称全仓旧代码清除。
- `tools/v3-directory-test.mjs`：11组实际API、组合函数和两完整页面隔离测试，子组件SideBar/Loading用适配器；覆盖真分页、第二页失败重试、空/收缩、特殊名称ID路径、身份竞态/轮换/退出、SSR逃逸/白名单/种类绑定及卸载。
- `tools/v3-ssr-payload-test.mjs`：新增第11组，一次消费/目录绑定/再次投影/合法空结果与真实entry接线。
- `AGENTS.md`、`docs/V3_MIGRATION.md`、本记录。

## 安全与反漏扫复核

新增客户端只读既有固定GET，不新增匿名/写入口、anonymous.viewSkips或权限例外；BeforeRequestHandler黑名单、AnonymousViewCheckMidware与CaptchaProcessor链保持，实际新IP/验证码/解封/开发模式待运行回归。现有Bearer策略保持，不向旧apiKey传令牌、不新增Cookie写接口或CSRF例外。响应白名单、Vue文本和数字ID链接防敏感资料/HTML混入；无SQL、远程代理或SSRF抓取，无新增批量能力（最多一页50），SSR按应用隔离且读取不进SWR。没有新增CDN、上传下载路径或公网目录；生成JS版本审计0，无source map。生产目录枚举及实际授权仍待验收，不能默认通过。

## 人工完整测试步骤

1. 启动最新website_v3，进入顶栏“领域”和页脚“标签”；桌面及390px各验证首屏布局、总数、图标/无图标、特殊名称纯文本和0篇计数。若联调此前新增Java接口，先由用户通过IDEA重编译或重启后端。
2. 数据超过50时翻到第二页，确认总数/页数来自服务器、短末页禁止下一页；点击条目进入对应目录文章列表，C++等特殊名称不应被二次解码。
3. 单独阻断目录第二页，确认旧50项及总数清除且显示错误；解除后点“重试当前页”，仍读取第二页，标题不被固定顶栏挡住。刷新期间切页/离页，迟到结果不得覆盖。
4. 用成功空目录和目录收缩到一页验证空态、0总数、禁下一页及“返回第一页”；失败不得显示成成功空目录。
5. 当前身份读取期间退出/换号，旧结果不能恢复，页号回1；普通Token轮换保留页号并重新读取。SSR首屏成功不重复请求；SSR失败在客户端补读，不能用其他目录快照。
6. 分别以游客、新IP、受限账号、合法Bearer回归实际匿名盾/黑名单/验证码与权限。真实运行和窄屏未验项目单列，不以合成夹具代替。
