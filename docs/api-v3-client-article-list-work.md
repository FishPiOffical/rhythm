## 安全与反漏扫结论

- 沿现有/api/v3文章、目录、搜索、专栏GET的optionalContent/AnonymousViewCheckMidware门禁；没有修改Router全局BeforeRequestHandler、anonymous.viewSkips、CaptchaProcessor或登录中间件，没有新增公开入口/上传下载/代理地址。新IP首访/计次验证码、黑名单/test/validateCaptcha解封与开发关闭盾行为依赖实际后端，未在本轮夹具中验收。
- 只读GET，无新增CSRF写面；当前读者用既有内存Bearer，不传旧apiKey/建页面Cookie。身份改变清旧且拒迟到，公开SSR逐请求/目标绑定，无SWR回退；旧Home聚合缓存/假空仍单列待处理。实际权限与第三方scope仍须真实服务验证，前端不能代替后端可见性校验。
- 固定接口路径和排序，目录别名只映射实际ID，搜索单次编码且沿服务器100单位限制，无SQL拼接/远程抓取/SSRF；Vue文本输出，不使用接口permalink导航、不渲染未经清洗HTML。标准DTO白名单，正文/凭据/隐藏作者不可从旧别名恢复。
- 响应p/size/数量/ID去重/时间/总页数校验，每请求20文章或12专栏；目录别名解析沿既有有界目录预算，未宣称完整目录大规模性能或跨查询事务快照。重复HTTP读无业务写入副作用。新静态/CDN资源、公开文件路径、目录路由均无新增；生成JS版本/map扫描通过，生产目录枚举与部署缓存策略未实际验证。
