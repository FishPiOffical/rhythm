## 规则与行为

仅企业入驻，单张JPEG/PNG原图最多5MiB。客户端检查大小和头尾签名，不代替服务端完整解码、有效图片与预算校验，不根据扩展名信任内容。选图只读本地，显式确认才以原始二进制发送既有第一方接口，不先上传图床，也不以URL/私信提交。预览地址仅本地Blob，关闭、离页、退出回收。

同一未知提交保留同一图片字节、MIME与key；不能替换图片后复用key，正常刷新token不清理。同键历史回执仅id/createdAt，随后重新读列表/详情；不把原提交回执当当前pending。已读取并销毁的材料可以仍待审核结论，重放不补回材料。恢复后的4xx不证明最初没有提交，保留恢复命令；首次明确失败可重新选择。已有pending返回409并重新读列表，后置读取失败不得变成再次提交。

原图不进入Pinia可序列化state、URL、持久化存储或日志；未知材料仅当前登录内存，跨SPA保留而非跨整页刷新。离页清未提交草稿，已经明确确认的在途/未知请求保留恢复上下文；退出或换号全部清理，异步读取/响应不能污染新身份。服务端审核员首次成功读取销毁与审核决定是独立操作，本人不能取回原图，本批无审核决定操作。

## 完整人工链

1. 本批只改客户端。真实联调前，请先由IDEA重新编译或重启此前Java/FTL，并部署认证与凭据迁移；前端yarn run build，代理开发后端。第一方登录→设置→认证，读本人历史及详情，匿名/其他用户/第三方不得取本人材料或记录。
2. 用隔离测试账号选择JPEG/PNG，选图和预览不得发上传请求；取消确认无写。空文件、GIF/PDF、超过5MiB、损坏图片应拒绝；服务端完整解码失败不能产生申请。非法替换必须清掉旧草稿，不能误发先前图片。
3. 明确确认提交，成功得到id/时间，再读当前状态。模拟提交已成功但丢响应，切设置其他页再返回，同key同原字节恢复同申请，无第二份申请或材料复活；普通401刷新保留恢复，退出/换号清理。整页刷新先查询本人记录，不盲目重投。
4. 同用户未处理申请含已读材料但未给结论时，新key返回409；同key返回原回执。审核员真实一次读取需由授权人员在测试库另验：本人页面显示材料已读取且仍待结论；再给通过/驳回，刷新显示真实结论和说明，不自动发勋章。
5. 记录超过20条检查上一页/下一页、末页；第二页503后分别重试和返回首页，不能显示旧页冒充新页。详情503单独刷新，包含HTML符号的说明仅纯文本，不执行标签。当前详情不能被之前其他ID的迟到响应覆盖。
6. 预览、选图、确认与请求在途离页/退出/换号，旧图/申请/确认不得留给新用户；PC/移动、键盘文件选择、真实Cookie/Bearer、失效授权及黑名单/test/解封另行回归。
