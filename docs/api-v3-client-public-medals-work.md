## 完整人工测试链

1. 从用户资料进入 `/member/{userName}/medals`，游客与登录用户分别检查当前公开有效记录、真实总数/顺序/期限；名称和描述中的HTML必须原样文本展示。重复授予不应按同定义ID丢项。
2. 准备超过20条记录，下一页/上一页和刷新应请求当前p、size20；末页按钮禁用，切到短末页应滚回内容。空用户显示真实0条，非法/不存在用户显示错误，不显示旧资料。
3. 模拟第二页503，旧行和总数消失；重试应仍为第二页，返回第一页操作重置页码。404或缺scope不得回退旧端点。隐藏/到期记录应由真实后端排除，客户端不凭本机时钟另行过滤。
4. 快速切换目标、正常token轮换、退出/换号和离页并延迟旧请求，旧结果不得覆盖当前目标；同账号轮换保留页码，身份改变重置首页。
5. 桌面及390px检查三列/一列、长名称/描述、键盘焦点和分页可用性。当前仅元数据展示，不应出现旧图像生成请求、完整用户对象或敏感资料。
6. 真实服务验证游客匿名校验、登录profile.read、停用账号、黑名单跳/test、首访/周期验证码及validateCaptcha解封、开发风控关闭和频繁请求拒绝。以上真实运行链本批未验。

## 安全与反漏扫结论

已有路由仍由optionalProfile和AnonymousViewCheckMidware保护，不改BeforeRequestHandler、验证码解封或anonymous.viewSkips。只读GET，无新增Cookie写或CSRF接口；身份迟到隔离和白名单避免跨身份旧数据传播，权限仍以后端当前判断为准。纯文本避免XSS，用户名闭集与编码不拼SQL，不抓取远程图片避免新增SSRF路径；前后页按钮及加载状态限制重复交互，未新增批量查询。无新SQL、上传/下载路径、目录或CDN；产物版本和map静态检查通过。真实未鉴权/越权/缺scope、风控/目录枚举响应与后端过滤未运行验收，必须补验。
