## 继续维护

- 每轮主动核对是否触发 [维护与完成标准](maintenance.md#维护触发与完成标准)，交付前完成更新或说明无需更新的理由；所有材料均遵守 [文档保密要求](maintenance.md#文档保密要求)，不得保存真实凭据或其他涉密内容。
- 根文件只放会影响所有任务的最高优先级约束；模块细节更新本目录已有专题。新主题建语义清晰的文件并补上本表，命中多个主题时拆开条目并相互链接。
- 已有 `docs/` 专项设计、部署、验收记录继续在原文件维护，专题给出必读入口和不易发现的限制；不要全文复制，避免两处事实各自变化。
- 先检索原约定再修改同一处。移除重复前核对限制、例外、兼容、迁移、安全边界和未验证项，不能只留下摘要；过期结论标明替代依据，历史事实保留到 [历史专题](history.md) 或对应记录。
- 根文件、专题索引、Claude/Gemini入口和迁移记录是不同职责。`migration-map.md` 只追溯本次整理，不为后续每个提交追加流水账；任务过程放 `.codex-tasks/`。
