## 完整人工测试步骤

1. 以游客和登录账号分别从列表进入可读文章，确认正文/20条评论/热度等各自状态；刷新SSR和从其他文章进入都应显示当前目标。公开SSR失败应先骨架再当前GET。
2. 评论超过一页时输入未发送草稿，点击下一页；读取期间提示正在读取，分页按钮禁用；正常结果更新评论、末页禁下一页，原挂载编辑器的草稿不因请求发起而清掉。
3. 阻断第二页GET，旧正文/评论不得继续显示；解除后“重新加载”仍读第二页，不自动重发任何评论或付费命令。
4. 当前文章可见性收回或删除后，使当前读取返回401/403/404；普通读取、评论成功后的重读、置顶后的重读、实时“读取最新内容”分别验证正文/评论/回复引用/图片/历史消失。若只是503，确认操作后应显示专用重读提示，按钮只发GET。
5. 输入评论草稿并打开历史，同账号Token自动轮换后应当前重读且保留面板/草稿；退出换号清掉私有状态。加载期间切目标/页号/退出/离页，旧响应不得填回。
6. 桌面与390px、普通文章与长篇段评/付费区各回归；用新IP、黑名单和合法apiKey/Bearer验证既有风控与权限链。真实受限账号、支付/写入操作仅由用户在专用测试环境人工执行。
